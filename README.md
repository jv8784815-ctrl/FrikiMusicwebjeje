# FrikiMusic web

Sitio estático (HTML/CSS/JS) para Vercel.

- `css/md3.css`: tokens y tema claro/oscuro de Material 3.
- `css/m3-expressive.css`: capa M3 literal (botones, chips, segmented, FAB, snackbar, carrusel, ventanas).
- `js/m3-motion.js`: ripple, revelado al scroll, FAB, carrusel arrastrable y escritorio de ventanas movibles.
- `assets/img/pc-*.webp`: capturas de FrikiMusic Desktop y composiciones.
