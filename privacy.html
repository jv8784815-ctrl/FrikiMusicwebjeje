Política de Privacidad

Última actualización: 24 de agosto de 2026

FrikiMusic es una aplicación musical desarrollada por FrikiBot Studio. Esta política explica qué información puede procesarse cuando utilizas FrikiMusic y, especialmente, cuando decides conectar tu cuenta de Google/YouTube.

1. Información que procesamos

FrikiMusic puede funcionar sin que conectes una cuenta de Google. Para las funciones que requieren integración con YouTube, puedes autorizar voluntariamente el acceso mediante Google.

La integración de YouTube utiliza el permiso:

youtube.readonly

Este permiso permite a FrikiMusic consultar información de YouTube que necesitas para determinadas funciones de tu biblioteca, como playlists y contenido asociado a ellas. FrikiMusic no solicita permisos para modificar, publicar ni eliminar contenido de tu cuenta de YouTube.

2. Información de Google/YouTube

La autenticación se realiza mediante los mecanismos de Google. FrikiMusic no recibe ni almacena tu contraseña de Google.

La información obtenida mediante la autorización se utiliza únicamente para proporcionar las funciones de FrikiMusic que dependen de tu biblioteca de YouTube, como consultar y mostrar el contenido disponible para tu cuenta.

3. Cómo utilizamos la información

La información obtenida mediante la API de YouTube puede utilizarse para:

  • mostrar tus playlists dentro de FrikiMusic;
  • consultar las canciones o vídeos asociados a dichas playlists;
  • proporcionar las funciones de biblioteca que hayas solicitado;
  • mantener el funcionamiento de las funciones de FrikiMusic que dependen de YouTube.

No utilizamos los datos de YouTube para vender información personal ni para crear perfiles publicitarios.

4. Almacenamiento y conservación

FrikiMusic procura procesar únicamente la información necesaria para ofrecer sus funciones. La información de Google/YouTube se utiliza en el contexto de la función para la que concediste autorización.

FrikiMusic no almacena tu contraseña de Google. Cuando corresponda, determinados datos técnicos o estados de sesión pueden conservarse localmente en tu dispositivo o en los servicios necesarios para que la aplicación funcione.

5. Servicios de terceros

FrikiMusic puede utilizar servicios de terceros para funciones como autenticación, información musical, letras, reproducción, alojamiento y funcionamiento de la aplicación. Estos servicios pueden procesar información conforme a sus propias políticas y condiciones.

En particular, la integración con YouTube utiliza servicios de Google y está sujeta a las políticas aplicables de Google.

6. YouTube API Services

FrikiMusic utiliza YouTube API Services para proporcionar funciones relacionadas con la biblioteca del usuario. El uso de la información recibida desde YouTube se realiza de acuerdo con las políticas aplicables de Google, incluida la Google API Services User Data Policy.

7. Seguridad

Aplicamos medidas razonables para proteger la información que procesa FrikiMusic. Aun así, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

8. Revocar el acceso

Puedes retirar en cualquier momento el acceso concedido a FrikiMusic desde la configuración de seguridad de tu cuenta de Google. También puedes dejar de utilizar la integración con YouTube desde la propia aplicación.

9. Privacidad de menores

FrikiMusic no está diseñada para solicitar deliberadamente información personal de menores. No recopilamos conscientemente información personal de menores con fines comerciales.

10. Cambios en esta política

Podemos actualizar esta Política de Privacidad cuando cambien FrikiMusic, sus funciones o los requisitos aplicables. La fecha de actualización se indicará al principio de esta página.
